# Care Tracker (code name)

A cross-platform mobile app for scheduling, logging and analyzing recurring care routines for anything:
pets, plants, aquariums, sourdough starters, medications, home maintenance, or fully custom items.
It's built on a modular, data-driven system: each category is a declarative *module*, and the scheduling, logging, reminders,
insights and sharing engines are generic.

**Status:** Phase 0 (planning). No application code yet.
