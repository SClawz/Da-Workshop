# Routine Timer (code name)

A cross-platform mobile app that combines a **multi-timer** with a **routine tracker**:
- **Multi-timer:** countdowns, stopwatches, interval sequences, and "finish together" timer groups, all running at once and reliable with the app closed.
- **Routine tracker:** scheduled routines with timed steps and time goals.
- **Visualization:** data visualization for both.

**Status:** Phase 0 (planning). No application code yet.
